# LetsPing - Real-Time Chat Application (LetsPing)

A modern real-time messaging platform built with Next.js, featuring direct messaging, channels, voice messages, file sharing, AI insights, and end-to-end encryption.

## Live Demo

https://aryan-realtime1chat.insforge.site

## Preview

LetsPing provides a modern Discord-inspired interface for seamless communication and collaboration.

## Features

### Messaging
- Real-time messaging
- Direct messages (DMs)
- Channel-based communication
- Message search
- Readable chat interface

### Media & Sharing
- Voice message support
- File sharing
- Shared files panel
- Media attachments

### Security
- End-to-end encryption
- Shared passcode protection
- Secure communication

### AI Features
- AI Insights panel
- Smart conversation analysis
- AI-powered enhancements
- AI summarization

### User Experience
- Dark mode UI
- Responsive design
- User profiles
- Online/Offline status
- Modern dashboard layout

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase/Firebase
- Insforge Deployment

## Installation

Clone the repository:

```bash
git clone https://github.com/aryansingh3107explo/realtime-chatapplication.git
```

Navigate to the project:

```bash
cd realtime-chat
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
